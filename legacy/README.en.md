# Previous Py-Apple Dog versions

The fifth generation is maintained independently in `py-apple-quadruped-robot-AI`. Earlier robots using traditional motion control remain in their original repositories with their tutorials, filenames, and directory structure preserved.

| Historical project | Resources |
| :---: | :---: |
| [Original Py-Apple Dog project](https://github.com/ToanTech/py-apple-quadruped-robot) | Original homepage, build guide, video tutorials, and combined resources |
| [Py-Apple Structure](https://github.com/ToanTech/py-apple-structure) | Earlier mechanical structures and printing resources |
| [Py-Apple Dynamics](https://github.com/ToanTech/py-apple-dynamics) | Traditional quadruped motion-control software |
| [Py-Apple Controller](https://github.com/ToanTech/py-apple-controller) | Earlier controller boards and circuits |
| [Py-Apple BLDC](https://github.com/ToanTech/py-apple-bldc-quadruped-robot) | Brushless quadruped experiments |

This directory links to the historical projects; it does not duplicate their source code or CAD files.

# 菠萝狗历史版本

第五代菠萝狗在 `py-apple-quadruped-robot-AI` 中独立维护。此前的传统控制版本继续保留在原仓库，原有教程、文件名称与目录结构不变。

| 历史项目 | 内容与入口 |
| :---: | :---: |
| [菠萝狗原项目](https://github.com/ToanTech/py-apple-quadruped-robot) | 原版首页、搭建指南、配套视频教程及整合资料 |
| [Py-Apple Structure](https://github.com/ToanTech/py-apple-structure) | 历史机械结构与打印资料 |
| [Py-Apple Dynamics](https://github.com/ToanTech/py-apple-dynamics) | 传统四足运动控制软件 |
| [Py-Apple Controller](https://github.com/ToanTech/py-apple-controller) | 历史控制板与电路资料 |
| [Py-Apple BLDC](https://github.com/ToanTech/py-apple-bldc-quadruped-robot) | 无刷四足实验版本 |

本目录提供历史项目入口，不重复收录旧版源码与 CAD 文件。
